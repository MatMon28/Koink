# File map: root configs, `scripts/`, `public/`

> **Scope:** everything outside `src/`, `android/` and `docs/`.
>
> **Read when:** you change the build, a script, the manifest or an icon.
>
> **Related:** [../prepare-apps.md](../prepare-apps.md), [../pwa.md](../pwa.md), [../brand.md](../brand.md)

## Root

| File | Role |
| --- | --- |
| `package.json` | Name `koink`, version, scripts (below), dependencies. Capacitor core / android / cli are pinned to one version |
| `package-lock.json` | Exact dependency versions; `npm ci` uses it |
| `vite.config.ts` | Vite config: React and Tailwind plugins, and `offlineWorker()`, the build step that writes `dist/offline-worker.js` from the template (skipped in `--mode android`). The optional `.vite-source-tags.js` import and the `process.env` defines come from the project template |
| `capacitor.config.json` | Capacitor configuration (app id, scheme, `LocalNotifications` icon, `SystemBars`, Android options). Every key is explained in [../android.md](../android.md#capacitorconfigjson) |
| `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json` | TypeScript project references: `app` covers `src/` (strict, `react-jsx`), `node` covers `vite.config.ts` |
| `eslint.config.js` | ESLint flat config for `*.ts` / `*.tsx`: recommended JS + TypeScript rules, React hooks, `react-refresh` |
| `index.html` | See [app-shell.md](app-shell.md) |
| `.gitignore` | `node_modules`, `dist`, editor files |
| `.vercelignore` | Keeps `android/` out of Vercel uploads |
| `README.md` | Overview and the file legend |

### npm scripts

| Script | Does |
| --- | --- |
| `npm run dev` | Vite dev server with hot reload (no offline worker) |
| `npm run build` | `tsc -b && vite build` -> `dist/` (website + PWA) |
| `npm run preview` | serves `dist/` locally |
| `npm run lint` | `eslint .` |
| `npm run brand` | `node scripts/render-brand.mjs` (needs `npm i --no-save sharp`) |
| `npm run android:splash` | `node scripts/generate-splash-themes.mjs` -> `android/app/src/main/res/values/splash_themes.xml` |
| `npm run package` | `node scripts/package-project.mjs` -> `public/downloads/koink-project.zip` |
| `npm run android:prepare` | `node scripts/prepare-android.mjs` |
| `npm run android:open` | `cap open android` (Android Studio) |

## `scripts/`

| File | Role |
| --- | --- |
| `offline-worker.template.js` | Source of the service worker, with the tokens `'__BUILD_ID__'` and `['__PRECACHE__']` that the build fills in: precache, fetch strategy, and the `notificationclick` handler for reminders. Edit this, never `dist/offline-worker.js` |
| `render-brand.mjs` | Writes every static copy of the brand from `src/brand/art.js`: `public/favicon.svg`, `public/brand/*` (icon, wordmark and animations in light and dark, the sheet), PWA icons, Android launcher / themed / notification icons |
| `generate-splash-themes.mjs` | Writes one Android launch-screen style per app background (`Splash_<hex>`), from the `--bg` values in the stylesheets and the Mono palette. `--check` only compares |
| `prepare-android.mjs` | Guards the Capacitor config, type-checks, builds with `--mode android`, removes `dist/downloads` and `dist/brand`, runs `cap sync android`, then verifies the synced bundle, the plugin list (four plugins), the native launch pieces and that `splash_themes.xml` is up to date |
| `package-project.mjs` | Writes the project archive: walks the repository, skips installed / generated files and the archive itself, and writes the zip with Node's zlib (file modes kept, so `gradlew` stays executable) |

## `public/` (copied to `dist/` as it is)

| File | Role |
| --- | --- |
| `favicon.svg` | The app icon as the browser favicon: one file with the light and the dark version, switched by the browser's colour scheme. Generated |
| `brand/` | The brand sheet (`index.html`) and every asset in light and dark: icon (SVG + 512 px PNG), wordmark, the five launch animations. Generated by `npm run brand`; not precached, not shipped in the APK |
| `manifest.webmanifest` | Web app manifest: names, colours, display mode, icons, the two launch shortcuts |
| `icons/icon-192.png`, `icons/icon-512.png` | Manifest icons, purpose `any` |
| `icons/maskable-512.png` | Manifest icon, purpose `maskable` |
| `icons/apple-touch-icon.png` | iOS home-screen icon (linked from `index.html`) |
| `downloads/koink-project.zip` | The whole project as one archive, offered by the "Project files" card in Settings. Generated by `npm run package` and committed; not precached by the offline worker, not shipped in the APK |

## Generated, not in the repository

`dist/` (build output, including `offline-worker.js`), `node_modules/`, and the synced files inside `android/` listed in [android-native.md](android-native.md).
