# File map: `src/lib/`

> **Scope:** state, types, calculations and every non-visual module.
>
> **Read when:** you change behaviour rather than appearance.
>
> **Related:** [../data-model.md](../data-model.md), [../architecture.md](../architecture.md)

| `store.tsx` | `AppProvider`, `useApp`, `useSheet`, `useToast`, `useStorageStatus`, `Toast` | The only state container. ## Dependencies between them

`types` <- everything. `storage` <- `store`, `themes`. `platform` <- `back`, `pwa`, `store`, `notifications`, `useReminders`. `tabs` <- `Tabs`, `PageSwiper`. `calc` uses `categories`, `dates`, `format`. `store` uses `calc`, `dates`, `demo`, `format`, `platform`, `reminders`, `storage`, `themes`. `earlyStart` uses `intro`, `spring`, `storage`, `themes` only (keep it that small); `intro` takes its art from `src/brand/art.js`. `notifications` uses `reminders`; `useReminders` uses both and `store`. Nothing in `lib/` imports from `components/`, `pages/` or `sheets/`.
| `inflation.ts` | `personalInflation`, `inflationTrend`, `inflationWindows`, `inflationCandidates`, `InflationOptions`, `Inflation`, `RepeatItem` | Personal inflation maths: spending change and repeat-purchase price change of the last N completed months against a year ago or the period before, with excluded expenses left out | [../features/statistics.md](../features/statistics.md) |
| `scrollFade.ts` | `startScrollFade`, `fadeEdges` | Measures every `[data-scroll-fade]` element and sets `data-fading`, `--fade-start`, `--fade-end` for the border fade mask in `index.css` | [../design-system.md](../design-system.md#border-fade-on-scrolling-fields) |
